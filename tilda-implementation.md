# MIRA CORP — структура сайта для Tilda

## Формат

Сайт собран как адаптивный HTML/CSS-прототип для переноса в Tilda. Его можно использовать двумя способами:

1. **Быстрый перенос:** добавить один блок `T123 HTML-код`, вставить содержимое `index.html`, а стили из `styles.css` поместить в `Настройки сайта → Еще → HTML-код для вставки внутрь HEAD` внутри тега `<style>...</style>`.
2. **Правильная сборка на Tilda:** собрать страницу секциями в Zero Block по структуре ниже, загрузив изображения из папки `assets`.

## Блоки страницы

### 1. Header

Высота: 88-104 px desktop, sticky/fixed.

Элементы:
- Логотип MIRA слева.
- Меню: `О компании`, `Направления`, `Бренды`, `Новости`, `Карьера`, `Контакты`.
- Переключатель языка с иконкой: `RU`, `EN`, `TR`, `AR`, `FA`.

Поведение:
- В обычном состоянии логотип белый.
- При наведении и фокусе логотип становится фирменно-синим `#0051BA`.
- Языковой список открывается по клику на иконку/код языка.

### 2. Блок 01 — направления

Основной экран:
- H1: `Создаем бренды будущего.`
- Текст: `Мы создаем, развиваем и масштабируем компании, которые делают повседневную жизнь миллионов людей лучше.`
- CTA-кнопок в левом блоке нет; переходы остаются внутри карточек направлений.

Карточки:
- `FMCG` — потребительские товары повседневного спроса нового поколения.
- `AI & Technology` — искусственный интеллект и технологии, меняющие индустрии.
- `Sustainable Energy` — устойчивые энергетические решения для лучшего будущего.
