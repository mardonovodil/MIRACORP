# MIRA CORP Website

Static website for GitHub Pages.

## GitHub Pages URL

After enabling GitHub Pages for this repository:

`https://mardonovodil.github.io/MIRACORP/`

## Tilda Loader

Paste this into one Tilda `T123 HTML` block:

```html
<div id="mira-site"></div>
<script src="https://mardonovodil.github.io/MIRACORP/tilda-widget.js"></script>
```

After this, update files in GitHub and the Tilda page will load the newest published version.
